# 网站登录

`server.py` 是独立的单用户登录服务，由服务器上的 `credentials.json` 验证密码，配置文件不放在仓库。账号密码通过服务器端验证，登录状态保存在服务内存中，服务重启后需要重新登录。错误次数过多会暂时限制登录。

`nginx-terms.conf` 仅处理 `terms.aifluxor.com`，通过内部认证请求保护雷达页面。公开 GitHub 仓库中的报告仍然公开，网站登录并不会自动保护仓库里的数据。管理同行名单仍使用原有的 GitHub 管理员授权。

登录服务运行在 Docker 的内部网络中，不直接开放公网端口。需要恢复公开访问时，应先由管理员确认，再从现有备份恢复该域名的原 Nginx 配置并重新加载；不要删除或打印凭据文件。
